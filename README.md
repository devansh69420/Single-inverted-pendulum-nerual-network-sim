# Single-inverted-pendulum-nerual-network-sim
A custom Java simulation of a Single Inverted Pendulum (SIP) system. This project implements dynamic physical simulation using 4th-Order Runge-Kutta (RK4) integration, an LQR controller with heuristic swing-up logic, and a custom Neural Network engine built entirely from scratch (without external libraries) to attempt end-to-end behavioral cloning.
